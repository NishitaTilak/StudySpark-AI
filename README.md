# StudySpark AI – Your Personal Study Buddy

## About the Project
StudySpark AI is an AI-powered study assistant designed to make learning easier, more interactive, and engaging for students. It helps students understand difficult concepts, review key points, and improve their knowledge through practice and challenges.

## Features
- **Understand:** Simplifies difficult topics into student-friendly explanations.
- **Practice:** Helps students revise concepts through practice questions.
- **Challenge:** Tests knowledge with interactive quizzes.
- **Spark Points:** Encourages learning through gamification.
- **Multiple Learning Levels:** Supports beginner, intermediate, and advanced learning.

## Technology Stack
- Python
- Streamlit
- Ollama (local AI model)
- Requests

## How to Run Locally
1. Install Python.
2. Install the required libraries:
   ```bash
   pip install -r requirements.txt
   ```
3. Install Ollama and download a supported model if using the local AI functionality.
4. Start the application:
   ```bash
   streamlit run app.py
   ```

## Note
The AI features that depend on Ollama require Ollama to be installed and running on the computer where the application is launched.

## Project Goal
To make studying more personalized, accessible, interactive, and enjoyable for students.
